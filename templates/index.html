Verificando a conexão…

Estamos verificando se o MongoDB está ativo para abrir seu espaço de trabalho.

mongodb://localhost:27017
Como conectar
  1. Abra Serviços no Windows e inicie o serviço MongoDB.
  2. No MongoDB Compass, conecte usando o endereço acima.
  3. Clique em Tentar conexão. O banco será preparado automaticamente.

O Compass é a interface de gerenciamento. O serviço MongoDB precisa estar em execução.

Sem conexão, os dados e as ações ficam indisponíveis.
